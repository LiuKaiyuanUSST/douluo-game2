一、武魂系别分类

武魂分为七大系别：

│   系别   │             说明               │
├──────────┼──────────────────────────────────┤
│   烈焰   │             火系                │
│   苍木   │             木系                │
│   蛊毒   │             毒系                │
│   巨兽   │             兽系                │
│   雷霆   │             雷系                │
│   沧澜   │             水系                │
│   天工   │           独立体系              │
└─────────────────────────────────────────────┘

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

二、循环克制链

烈焰 → 苍木 → 蛊毒 → 巨兽 → 雷霆 → 沧澜 → 烈焰

每个系别克制其后一个系别：
· 烈焰克制苍木
· 苍木克制蛊毒
· 蛊毒克制巨兽
· 巨兽克制雷霆
· 雷霆克制沧澜
· 沧澜克制烈焰

天工系不参与此循环克制链。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

三、克制效果

当攻击方系别克制防御方系别时，每回合攻击有 50%
概率额外增加 1 点伤害。

· 该判定独立于攻击掷骰和防御减伤。
· 若触发，在计算完所有攻防数值后，最终伤害 +1。
· 此额外伤害不受减伤影响。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

四、天工系特性

· 天工系不克制任何系，也不被任何系克制。
· 专属效果：自身受到的所有系别伤害永久有 5% 概率
  减免（在防御减伤结算后、最终承伤时计算）。

五、主副系与出战规则

每名角色有固定的主系和副系。战斗前必须选择其一
出战：

┌─────────────────────────────────────────────┐
│ 出战选择 │ 主系魂技 │ 副系魂技 │ 其他五系  │
├──────────┼──────────┼──────────┼───────────┤
│ 主系出战 │   100%   │   80%   │    50%   │
│ 副系出战 │   80%    │   80%   │    50%   │
└─────────────────────────────────────────────┘
