━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

一、基础属性

每名角色拥有三项基础属性：力量、速度、智力。
每项属性取值范围为 0～7，三项总和固定为 9。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

二、衍生属性

1. 生命值

生命 = 力量 + 3

完全由力量单属性决定。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

2. 攻击力

第一步：计算攻击能力值

攻击能力值 = 力量 × 1.5 + 速度 × 0.5

（结果可能为小数）

第二步：档位与伤害范围

┌─────────────────────────────────────────────┐
│ 攻击能力值  │ 档位 │ 伤害范围 │ 期望伤害 │
├──────────────┼──────┼──────────┼──────────┤
│      0       │  0档 │    1     │   1.0   │
│    1～2      │  1档 │   1～2   │   1.5   │
│    3～4      │  2档 │   1～3   │   2.0   │
│    5～6      │  3档 │   2～3   │   2.5   │
│    7～8      │  4档 │   2～4   │   3.0   │
│    9～10     │  5档 │   3～4   │   3.5   │
│    ≥ 11     │  6档 │   3～5   │   4.0   │
└─────────────────────────────────────────────┘

伤害掷骰规则：伤害范围如「1～3」，表示从 {1, 2, 3} 中
等概率随机取一个整数，其余同理。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

3. 防御力

第一步：计算防御能力值

防御能力值 = 智力 × 1.5 + 力量 × 0.5

第二步：档位与减伤效果

┌─────────────────────────────────────────────┐
│ 防御能力值  │ 档位 │      减伤效果        │
├──────────────┼──────┼──────────────────────┤
│    0～3      │  0档 │ 0（无减伤）          │
│    4～6      │  1档 │ 0.5（50%概率减1）    │
│    7～9      │  2档 │ 1.0（固定减1）       │
│    ≥ 10     │  3档 │ 1.5（固定减1 +       │
│              │      │      50%概率额外减1） │
└─────────────────────────────────────────────┘

减伤结算规则：
· 固定部分：必定减免对应数值。
· 概率部分：独立判定，与伤害掷骰同时进行。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

4. 闪避

灵巧 = 智力 + 速度

以攻击方为基准，计算双方灵巧差值：

灵巧差值 = 防守方灵巧 - 攻击方灵巧

┌─────────────────────────────────────────────┐
│   灵巧差值    │        闪避概率            │
├───────────────┼─────────────────────────────┤
│    ≤ 2        │          0%                │
│    3～5       │         25%                │
│    ≥ 6        │         50%                │
└─────────────────────────────────────────────┘

注意：只有当防守方灵巧高于攻击方时，才可能触发闪避。
若防守方灵巧 ≤ 攻击方灵巧，闪避概率为 0%。

· 闪避成功 = 本次伤害为 0。
· 结算顺序：先判定闪避，命中后再判定防御减伤。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

5. 攻击距离

由速度单属性决定：

┌─────────────────────────────────────────────┐
│   速度   │ 攻击距离 │     可攻击范围       │
├──────────┼──────────┼──────────────────────┤
│   0～3   │    1     │      仅前1排         │
│   4～6   │    2     │      前2排           │
│   7～9   │    3     │      前3排           │
└─────────────────────────────────────────────┘

攻击距离差异可能导致远程白嫖（一方能攻击到另一方，
而另一方无法反击）。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

6. 魂力恢复

战斗开始时所有角色魂力为 0。

魂力恢复由智力单属性决定：

┌─────────────────────────────────────────────┐
│   智力   │     每回合开始恢复 SP           │
├──────────┼──────────────────────────────────┤
│   0～3   │              1                  │
│   4～6   │              2                  │
│   ≥ 7   │              3                  │
└─────────────────────────────────────────────┘

主动魂技消耗预计 1～3 SP，上限 3 SP。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

7. 攻击顺序

每回合按照速度从高到低轮流行动。
同速度者，行动顺序随机。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

三、战斗结算顺序

每回合单次攻击的完整结算流程：

1. 判定闪避（闪避成功 → 伤害为 0，结算结束）
2. 掷攻击伤害骰（等概率取伤害范围内的整数）
3. 判定防御减伤（固定部分 + 概率部分）
4. 计算净伤 = max(伤害 - 减伤, 0)
5. 判定克制额外增伤（50% 概率 +1，不受减免）
6. 天工幸运减免（若目标为天工系，每次伤害有 5%
   概率免伤）
7. 扣除生命
