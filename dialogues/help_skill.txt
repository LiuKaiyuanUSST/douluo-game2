一、魂技概率规则

魂技实际触发概率受出战系别影响：

┌─────────────────────────────────────────────┐
│  出战选择  │  主系魂技  │  副系魂技  │     │
│            │            │            │ 其他 │
├────────────┼────────────┼────────────┼─────┤
│  主系出战  │   100%     │    80%     │ 50% │
│  副系出战  │    80%     │    80%     │ 50% │
└─────────────────────────────────────────────┘

通用被动魂技不受此规则影响，必定触发。
