一、等级提升方式

· 主角等级：推进剧情即可提升主角等级。
· 其他角色等级：获得魂环可以提升其他角色的等级。
· 每提升一级，角色可获得相应数量的武魂魂技。

二、等级修正规则

以全场等级最高者为基准，计算等级差带来的属性修正：

┌─────────────────────────────────────────────┐
│   等级差   │           属性修正            │
├─────────────┼───────────────────────────────┤
│   低 1 级   │ 力量 -1，速度 -1             │
│   低 2 级   │ 力量 -2，速度 -2，智力 -1    │
│   低 n 级   │ 力、速、智各减 n             │
│   (n ≥ 3)  │ （最小为 0，即减到 0 为止）   │
└─────────────────────────────────────────────┘
